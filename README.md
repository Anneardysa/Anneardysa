### 🚀 Flagship Project

#### 🎮 [ArdysaModsTools (AMT)](https://github.com/Anneardysa/ArdysaModsTools)
*My personal flagship desktop project for Dota 2 / Source Engine mod management and asset delivery.*

- **Architecture:** MVP (Model-View-Presenter) with constructor dependency injection.
- **Hybrid UI:** Native WinForms embedding Microsoft WebView2 powered by React & Vite.
- **Safety First:** Atomic file transaction pipeline (`FileTransactionService`) with SHA-256 validation and automatic rollback.
- **Resilience:** Multi-tier CDN failover routing between Cloudflare R2 and Backblaze B2.
