### About Me

Software Developer based in **Indonesia** specializing in high-performance desktop engineering, game file system reverse-engineering, edge distribution pipelines, and community automation systems.

> [!NOTE]

### Featured Project

#### [ArdysaModsTools (AMT)](https://github.com/Anneardysa/ArdysaModsTools)
*All-in-one .NET 8 desktop modding suite for Dota 2 / Source Engine with real-time cloud asset delivery.*

- **Architecture:** MVP (Model-View-Presenter) with constructor dependency injection.
- **Hybrid UI:** Native WinForms with embedded WebView2 powered by React & Vite.
- **Data Safety:** Atomic file transactions (`FileTransactionService`) with SHA-256 validation and rollback safety.
- **Distribution:** Multi-tier CDN failover routing between Cloudflare R2 and Backblaze B2.
